QuikArit v0.3.0

Added the following functions:

  • Conversion -- hex2bin, dec2hex, bin2hex functions
  • Misc. -- Factorial and termial functions
  • Trigonometry -- Sine, cosine, tangent and arctangent
  • Slopes -- findSlopebyAngle and slopeAngle functions
  • Calculus -- Summation and product functions.
  • Statistics -- Standard deviation function.
  • Calculus -- Quadratic solver function.
  • Other -- Added some module subdivision to make code more organized.

Still in development

QuikArit v0.2.0

Patched matrix functions.

Patched hex conversion functions (support for lowercase).

Added the following functions:

  • Matrix Multiplication -- matrixmult(x: list, y: list) -> list
  • Matrix Determinant -- matrixdet(x: list) -> int
  • Complex Division -- ComplexDiv(x: str, y: str) -> str
  • NOR gate -- nor(x: bool, y: bool) -> bool
  • NAND gate -- nand(x: bool, y: bool) -> bool
  • Octal to Decimal conversion -- oct2dec(x: str) -> int
  • Octal to Binary conversion -- oct2bin(x: str) -> int
  • Other highly specific functions (used inside other functions)

Deprecated functions:

  • Get2Exp
  • modulo
  • Percent
  • Getxthroot

Still in development
