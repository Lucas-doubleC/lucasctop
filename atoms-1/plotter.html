Gráfico de funções reais

  • Lista de funções disponíveis:

  • Math.cos(x), Math.sin(x), Math.tan(x), ...variações de arco (Math.atan(x) etc.)

  • Math.round(x) - Arredonda para o próximo inteiro

  • Math.sign(x) - Retorna 1 se o número for positivo, 0 se nulo, -1 se negativo.

  • Math.log(x) - Logarítmo (base 10)

  • Math.sqrt(x) - Raiz quadrada

  • Math.cbrt(x) - Raiz cúbica

  • ** - operador de potência (ex. x**2)

  • Sempre use * para indicar multiplicações

  • Math.abs(x) - Módulo de x

  • Outros - veja em Documentação do JavaScript
