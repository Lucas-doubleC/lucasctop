Controles:

  • Para navegar na lista de componentes, pressione E para ir para a frente e Q para ir para trás.
  • Para criar o componente selecionado, pressione C.
  • Para conectar um componente ao outro, clique no nó de um dos componentes (bolinha preta) e, após isso, clique no nó desejado do outro componente*
  • *Atenção: Cheque se os nós dos componentes são input e output ou vice-versa, caso não, não conseguirá conectar os dois.

Sobre os componentes:

  • Fontes:
    • São fontes puras que retornam um valor booleano (Falso ou Verdadeiro, denotados como F (false) e T (true), respectivamente)
    • Têm apenas um nó de conexão, que é apenas um output.
  • Portões lógicos:
    • São componentes que têm três nós de conexão: 2 inputs (Booleanos) e 1 output (Booleano)*
    • Retornam um valor dependendo dos inputs e do tipo de portão (AND, OR, XOR)
    • *Exceção: O portão NOT tem apenas um input e um output.
    • Saiba mais aqui
  • Registrador de 4 bits:
    • São componentes que têm cinco nós de conexão: 4 inputs (Booleanos) e 1 output (4 bits, não é compatível com inputs booleanos)*
    • Retornam um valor de 4 bits, que pode ser usado no conversor para decimal ou o comparador.
  • Indicador de output:
    • São componentes que têm um nó de conexão: 1 input (Booleano)
    • Mostram se o input é Falso ou Verdadeiro (F ou T)
  • Conversor para decimal:
    • São componentes que têm um nó de conexão: 1 input (4 bits)
    • Mostram o valor de 4 bits em base 10 (decimal)
  • Comparador:
    • São componentes que têm quatro nós de conexão: 2 inputs (4 bits; mostrados como n1 e n2) e 2 outputs (Booleanos)
    • n1 > n2: Retornará 1 e 0 (separados nos 2 outputs)
    • n1 < n2: Retornará 0 e 1 (separados nos 2 outputs)
    • n1 = n2: Retornará 1 e 1 (separados nos 2 outputs)
