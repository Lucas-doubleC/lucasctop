Para decriptar mensagens, basta colocar o deslocamento do alfabeto negativo (ex. mensagem encriptada via deslocamento de 3 letras (direita) no alfabeto → coloque -3 no campo de deslocamento para decriptar (se fosse para a esquerda, seria 3.))

É um método que se utiliza do deslocamento de letras do alfabeto para encriptar mensagens.

Ex. abcdefg... → deslocamento para a direita (positivo) de 3 → defghi... abc
