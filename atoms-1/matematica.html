Derivadas

1ª Derivada

$$\large \frac{d}{dx}$$

É quanto o declive de uma determinada função muda.

Limite para determiná-la:

$$\large f'(x) = \lim_{h\to0} \frac{f(x+h)-f(x)}{h}$$

2ª Derivada / Derivada de segunda ordem

$$\large \frac{d^2}{dx^2}$$

É a derivada (a variação de declive de uma função) da derivada.

Integrais

Indefinidos

Caracterizado por ser a antiderivada de uma função, ou seja, a função cuja derivada é a função original, matematicamente:

$$\large \int f(x) \,dx = F(x) + C; \frac{d}{dx} F(x) = f(x)$$

O +C indica que, independemente da constante que estava dentro da função (ex. f(x) = x+1 → constante 1), a derivada seria a mesma.

Definidos

Para calculá-lo, geralmente, necessita-se da antiderivativa da função f(x). Com essa antiderivada, F(x), apenas se coloca os valores no limite baixo (o número no "pé" do integral) e os do alto (o no topo)

Matematicamente:

$$\large \int f(x) \,dx = F(x) + C → \int_{a}^{b} f(x) \,dx = F(b) - F(a)$$

Regra da potência

Quando temos uma função no formato:

$$\large f(x) = nx^y$$

Pode-se usar uma regra útil no cálculo diferencial, em que:

$$\large \int f(x) \,dx = \frac{nx^{y+1}}{y+1}$$

Para derivadas:

$$\large n \cdot \frac{d}{dx} f(x) = n \cdot yx^{y-1}$$

Exemplos

Suponha que:

$$\large f(x) = x^2$$

Pode-se usar a regra da potência, ficando:

$$\large \int f(x) \,dx = \frac{x^{2+1}}{2+1} → \frac{x^3}{3}$$

Essa regra também serve para derivadas:

$$\large \frac{d}{dx} f(x) = 2x$$
